# Changelog screenshots

The Pages changelog (`scripts/build-changelog.mjs`) lists every commit on `main`.
To attach screenshots to a commit, add images to this folder **in that commit**:

- `<name>-before.jpg` + `<name>-after.jpg` → shown as a drag slider
- any other image → shown as a single screenshot

Prefer JPEG (~1280px wide) to keep the site small.
