## 06 — Summit Race

You against seven full-physics rival Marios up Bob-omb Battlefield.

- [x] A grid of eight at the foot of the race route and a 3-2-1 countdown. Rivals are crowd racers with distinct cap colours.
- [x] The route is Koopa the Quick's, re-planned so Mario can run it (`crowdRoute.ts`). Gold dots show the way ahead; shortcuts are allowed.
- [x] Live standings by distance along the route, then finishing order. The results card shows place, time and best time (saved).
- [x] Rivals far behind the player get a gentle catch-up warp, so the race stays close. R restarts.
